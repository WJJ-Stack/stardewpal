# 星露谷智能问答 · StardewPal

基于《星露谷物语》社区 Wiki 构建的多模态 RAG 问答助手。

## 核心能力

**截图提问** — 上传游戏截图，系统分层识别：

1. OCR 提取界面文字（本地 RapidOCR，中文识别置信度 0.999）
2. 图标特征匹配（pHash 召回 + 多特征精排，只在文字缺失时启用）
3. 置信度路由：高置信直答 / 中置信 VLM 选择题 / 低置信请用户确认

**混合检索** — BM25（SQLite FTS5）+ 向量（sqlite-vec）+ RRF 融合，
覆盖 2002 篇文档 / 5948 个文本块 / 521 个物品实体。

**数值不走模型心算** — 品质倍率、加工倍率、利润计算全部由确定性工具函数完成。
实测：关闭工具后，品质计算与加工计算题的准确率均为 0%。

**跨域拒答** — 问其他游戏（原神/我的世界等）会明确拒绝，
不凭借训练记忆作答，避免无法核实的幻觉。

**本地嵌入** — bge-small-zh-v1.5 的 ONNX 量化版，23.3 MB，纯 CPU，
无需 GPU、无需 torch。

## 实测指标

自动生成 6 类题型评测集，真实模型（GLM-4-Flash）结果：

| 题型 | 完整链路 | 关闭 Agent/工具 | 差值 |
|---|---|---|---|
| 单事实 | 100.0% | 91.7% | +8.3 |
| 品质计算 | 91.7% | **0.0%** | **+91.7** |
| 加工计算 | 100.0% | **0.0%** | **+100.0** |
| 属性查询 | 91.7% | 100.0% | −8.3 |
| 跨文档对比 | 100.0% | 100.0% | 0 |
| 拒答 | 100.0% | 100.0% | 0 |
| **整体** | **96.9%** | **61.5%** | **+35.4** |

## 技术栈

- **后端**：FastAPI + SQLite（FTS5 + sqlite-vec）
- **嵌入**：bge-small-zh-v1.5 ONNX INT8（本地推理）
- **视觉**：RapidOCR（ONNX）+ 自建图标特征索引
- **模型**：GLM-4-Flash（可切换多家 OpenAI 兼容服务）
- **前端**：原生 JS，无构建步骤

## 架构

```
截图 / 文字
    ├── 视觉链路：OCR → 图标匹配 → VLM 兜底 → 置信度路由
    └── 文本链路：路由 → 混合检索 → 充分性判断 → 工具计算 → 生成
                                                    ↓
                                            带引用的回答
```
